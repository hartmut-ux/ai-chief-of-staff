# Sokratischer Fall-Interviewer (Socratic Case Interviewer)

A workshop skill for the EDIH.li CEO workshop «Working Systems Live». The assistant
interviews the CEO socratically about their own strategic case: exactly 5 questions,
one at a time, each building on the previous answer — no advice, no solutions, no
judgement. It closes with a brief mirror (max. 5 sentences) and can optionally save
the result as a case protocol (Fallprotokoll).

The five questions follow the Case Clinic canvas (after Otto Scharmer):

1. Core challenge
2. Perspective of the other stakeholders
3. Desired future
4. What to let go / what to learn
5. Where help is needed

## Usage context

- Morning workshop block (09:50, Presencing warm-up): participants install this skill
  and run it on their own case; results feed into the Case Clinics.
- Anytime afterwards: preparing a case consultation, a difficult conversation, or an
  overdue decision.

## File layout

Each environment gets a fully self-contained copy — no shared folders, no external
references. The content is identical across environments:

- `kimi/SKILL.md` — Kimi Work
- `claude/SKILL.md` — Claude Cowork
- `codex/SKILL.md` — Codex

## Language and tone

Skill content is written in German (Swiss spelling, `ss` instead of `ß`), `du`-form,
for a CEO audience using desktop apps — no terminal knowledge required. Tone: calm,
precise, respectful; silence is part of the method.
